# Data Science Portfolio

This repository showcases end-to-end Data Science projects that transform raw data into actionable insights through statistical analysis, machine learning and data visualisation.

---

## Repository Overview

The projects in this repository demonstrate the complete data science lifecycle, from data acquisition and cleaning to exploratory analysis, feature engineering, predictive modelling and communicating insights.

The portfolio emphasises reproducible analytical workflows and practical business applications across engineering, supply chain, manufacturing and operational environments.
